# Manaful

Have you ever wanted a unified mana system for all your magical ideas? Well this is the mod for you!
Manaful adds nothing but a mana system which is easy to use and practical for any and all magical applications of mana.

The texture for the mana hotbar icon was taken from malcolmriley's sprite respritory.
Found here: www.github.com/malcolmriley/unused-textures
